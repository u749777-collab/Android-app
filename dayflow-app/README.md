# DayFlow — Android

Блокнот-заметка с напоминаниями и тремя секциями: **Спорт**, **Учёба**, **Свободное время**.
Приложение собирается только под Android (Expo SDK 53, React Native 0.79).

## Что умеет

- Спорт и Учёба: задача + норматив + время ежедневного напоминания.
- Свободное время: лимит в минутах, таймер, автозачёркивание и уведомление по окончании.
- Поздравление при закрытии секции и всего дня, мотивация — если план не завершён.
- Ежедневный сброс в полночь, результат дня уходит в статистику.
- Все данные хранятся локально на телефоне, интернет не нужен.

## Быстрый запуск (разработка)

```bash
npm install
npx expo start --android
```

Сканируй QR-код в Expo Go или запусти на подключённом по USB устройстве.
В Expo Go уведомления ограничены — для полной работы собери APK.

## Сборка APK для телефона

```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview   # или: npm run apk
```

По окончании EAS даст ссылку и QR на `.apk`: открой его на телефоне,
разреши установку из неизвестных источников и установи.

Для Google Play нужен AAB:

```bash
eas build -p android --profile production   # или: npm run release
```

## После установки

1. Разреши уведомления (Android 13+ спросит при первом запуске).
2. Отключи экономию батареи для DayFlow (Настройки → Приложения → DayFlow →
   Батарея → Без ограничений), иначе MIUI/EMUI могут задерживать напоминания.
3. Проверь работу кнопкой «Проверить уведомление» в разделе Настройки.

## Структура

```
App.tsx            экран «Сегодня», навигация, модальные окна
src/theme.ts       цвета, отступы, градиенты
src/types.ts       типы данных
src/data.ts        хранение, ежедневный сброс, расчёты
src/notify.ts      Android-канал и все уведомления
src/motion.tsx     анимации интерфейса
src/screens.tsx    Статистика и Настройки
eas.json           профили сборки APK / AAB
preview.html       макет интерфейса для просмотра в браузере
```
